
# SpendWise — Personal Finance and Expense Tracker

SpendWise is a DBMS project designed to help users manage their income, expenses, categories, and monthly budgets through a simple and responsive web interface.

## Project Objectives

- Record and manage income and expenses.
- Categorize financial transactions.
- Calculate total income, expenses, and net balance.
- Search and filter transaction records.
- Generate monthly and category-wise reports.
- Manage monthly spending budgets.

## Technology Stack

- Frontend: React.js with Vite
- Backend: Node.js and Express.js
- Database: SQLite
- Database Language: SQL
- Charts: Recharts
- Styling: CSS3

## Database Design

The planned database consists of three main tables:

1. `categories` — stores income and expense categories.
2. `transactions` — stores financial transaction records.
3. `monthly_budgets` — stores monthly category-wise spending limits.

The database will use primary keys, foreign keys, constraints, and SQL queries to maintain data integrity.

## Main Modules

- Dashboard
- Transaction Management
- Category Management
- Reports and Analytics
- Monthly Budgets
